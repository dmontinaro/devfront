# devfront.dev

> **Real work → visible progress → better missions → stronger base.**

`devfront.dev` ist ein Open-Source-Produktkonzept, das echte Softwareentwicklung mit Menschen und Agents in einen Basebuilding-/City-Builder-Loop übersetzt.

Nicht „Jira mit XP“. Nicht nur ein Coding-Lernspiel. Die Kernidee ist, dass produktive Entwicklungsarbeit eine sichtbare persönliche Welt aufbaut.

## Kernloop

1. Ausbauziel für die eigene Base wählen
2. Passende Mission auswählen
3. Echte Entwicklungsarbeit leisten
4. Abschluss verifizieren
5. Skill XP, Ressourcen und sichtbaren Base-Fortschritt erhalten

## Ressourcendomänen

- **Build** — Features, UI, Implementation und Produktarbeit
- **Stability** — Tests, Bugfixes, Security und Reliability
- **Knowledge** — Dokumentation, Research, Architektur und Teaching
- **Trust** — Reviews, Mentoring und Zusammenarbeit
- **Automation** — Agents, CI/CD, DevOps und Tooling

## MVP-Richtung

Der erste Proof ist ein fokussierter **2D Vertical Slice**:

- persönliche Base
- fünf Gebäudefamilien
- drei echte Missionstypen
- hybrid verifizierte Arbeit
- hochwertiger Completion- und Reward-Moment

Bewusst noch nicht im MVP: 3D, Guilds, PvP, Firmenwelten, Recruiting, Tokens oder globale Ranglisten.

## Status

**Concept / Pre-Prototype.** Der nächste Schritt ist ein spielbarer Base-Prototyp, der den Loop `Mission → Abschluss → Reward → sichtbarer Ausbau` mit echten Nutzern testbar macht.
